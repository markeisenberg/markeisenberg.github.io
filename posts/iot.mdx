# IoT Design - Master's Thesis

My Master's thesis revolved around the creation of an Internet of Things (IoT) interface, which I named "HomeNodes". The interface was designed to project onto physical objects, allowing users to:

- Connect objects together via a touch-enabled wall interface.
- Interact by tapping their smartphone on different objects.

---

## Summary of the Project

The project followed these key steps:

1. Conduct low-fidelity prototyping sessions with users to explore possibilities in the IoT design space.
2. Research existing interactive systems for inspiration and benchmarking.
3. Construct a working prototype of the system.
4. Test with users, using observation and video analysis for feedback.
5. Develop a list of design considerations and feedback to refine the IoT interface.
