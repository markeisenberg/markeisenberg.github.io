# Event Buddy App - Hobby Project with Friends

## Introduction

This project started as part of a job interview where I was tasked with creating an event planning app. I decided to turn it into a hobby project by collaborating with my friends to research, evaluate, and enhance the application. This approach allowed us to create something meaningful and test our skills in UI/UX design and collaborative product development.
